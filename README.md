# Riccardo Pala — Portfolio

Sito portfolio statico in italiano, inglese e spagnolo. Include il portfolio, le gallerie dei progetti MuSeek e Financial RAG, la certificazione Confluent e i curriculum in HTML e PDF.

## Pubblicazione

GitHub Actions pubblica automaticamente il contenuto di `dist/` su GitHub Pages a ogni push sul branch `main`. Per attivare la prima pubblicazione, nelle impostazioni del repository selezionare **Settings → Pages → Source → GitHub Actions**.

Con il repository `riccardo-pala/riccardo-pala-portfolio`, l'indirizzo atteso è `https://riccardo-pala.github.io/riccardo-pala-portfolio/`.

## Aggiornamenti

Aggiornare i file del sito in `dist/` e inviare le modifiche al branch `main`. Il workflow `.github/workflows/pages.yml` esegue la pubblicazione.
